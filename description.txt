核心流程：生成 Seed CUDA 代码后分阶段优化

保留的关键优化维度：

1. Parallel Mapping Strategy（并行映射策略）
   定义：决定一个 thread block / kernel launch 负责哪块输出数据
   具体内容：
   - GEMM：按输出 tile 切分
   - MoE：按 token 切分 vs (token, expert) 二维切分
   - Attention：按 sequence / head / block 切分
   影响：负载均衡、SM 利用率、launch 开销

2. Block Tiling（块级分块）
   定义：确定每个 thread block 处理的 tile 大小
   具体内容：
   - TILE_M, TILE_N, TILE_K 或 blockDim 的大小选择
   - Tile shape 的选择（如 128×128 vs 64×256）
   - 通过 tile size 控制 shared memory 分配和寄存器压力
   影响：shared memory 使用量、寄存器复用、occupancy

优化的四个阶段：
1. Seed 代码生成：基于问题描述生成初始 CUDA kernel
2. 并行映射优化：调整数据到 thread block / launch 的映射策略
3. 块级分块优化：调整 tile 大小和形状
4. 迭代修复与精化：基于性能反馈、NCU 指标和编译/运行错误进行迭代优化
